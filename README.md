# ОКТАВА

Браузерная музыкальная студия в стиле FL Studio.

## 🎛 Возможности
- Паттерны и пиано-ролл
- Схема песни
- Свои звуки (drag & drop аудиофайлов)
- Эффекты и автоматизация
- Экспорт в MP3, WAV, MIDI
- Локальное хранение проектов

## 💻 Технологии
- HTML5, CSS3, Vanilla JavaScript
- Web Audio API
- Node.js (локальный сервер)

## 🚀 Запуск проекта

### Способ 1: Локальный сервер (Рекомендуется)
Для корректной работы всех функций (особенно загрузки своих звуков и экспорта) рекомендуется запускать проект через локальный сервер.

1. Убедитесь, что у вас установлен [Node.js](https://nodejs.org/).
2. Откройте терминал (командную строку) в папке с проектом.
3. Запустите сервер командой:
   ```bash
   node server.js
